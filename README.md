# Doofus Adventure

A Unity 6 3D game prototype created for the Hitwicket Game Developer Challenge.

## Current status

Levels 1–3 are complete: JSON-driven movement, timed platform spawning, scoring, and start/game-over/restart flow are implemented.

## Planned gameplay

- Move Doofus with WASD or arrow keys.
- Navigate between timed green Pulpit platforms.
- Earn points by reaching a new platform.
- Avoid falling as platforms disappear.

## Project requirements

- Unity Editor: 6000.2.7f2
- Platform: Windows

## Controls

- **WASD** or **arrow keys**: move Doofus
- Follow the floating gold beacon to see where the next Pulpit will appear.
